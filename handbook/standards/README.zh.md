## 原则

标准是**可检验的陈述，而不是愿望**。新标准通过
[持续改进引擎](../../ai/orchestration/continuous-improvement-engine.md)提出，一旦被接受，
就成为[公司记忆](../../ai/memory/company-memory.md)的一部分。
