# 文档模板

[English](README.md) | 中文

全公司的填空式文档。把你需要的那份复制到工作目录。

| 模板 | 何时使用 |
|---|---|
| [prd.md](prd.md) | 定义产品或重大功能 |
| [rfc.md](rfc.md) | 提出重大的技术或流程变更 |
| [adr.md](adr.md) | 记录一项架构决策 |
| [incident-report.md](incident-report.md) | 记录事故及其复盘 |
| [research-report.md](research-report.md) | 汇报一项研究调查 |
| [security-review.md](security-review.md) | 评审一项变更或系统的安全性 |
| [release-checklist.md](release-checklist.md) | 交付一次发布 |
| [meeting-notes.md](meeting-notes.md) | 记录会议中的决策与行动项 |
| [status-report.md](status-report.md) | 每周 / 每月的进展汇报 |
| [okr.md](okr.md) | 设定季度目标与关键结果 |
| [one-pager.md](one-pager.md) | 在写完整 PRD 或 RFC 之前就一个想法达成一致 |
| [offer-letter.md](offer-letter.md) | 发出录用通知 |
| [employment-agreement.md](employment-agreement.md) | 有约束力的劳动合同（仅结构） |
| [board-update.md](board-update.md) | 定期的董事会 / 投资人更新 |
| [sales-proposal.md](sales-proposal.md) | 向客户提案，以他们的成果为锚点 |
| [qbr.md](qbr.md) | 与客户进行的季度业务回顾 |
| [dpa.md](dpa.md) | 面向供应商或客户的数据处理协议 |

所有模板在适用处遵循[通用输出格式](../../governance/universal-output-format.md)。

> ⚠️ 法律模板（[employment-agreement.md](employment-agreement.md)、[dpa.md](dpa.md)）是
> **结构性检查清单，而不是法律意见**。必须由法律顾问评审，且签署需要
> [人工审批](../../../ai/orchestration/approval-engine.md)。
