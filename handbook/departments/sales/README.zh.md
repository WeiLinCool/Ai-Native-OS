# 销售

[English](README.md) | 中文

销售把合格的兴趣转化为付费客户与持久关系。它掌管拓客、需求探索、方案匹配、谈判与成交 —— 起初由创始人主导，之后成为可重复的动作。它按[市场进入](../strategy/go-to-market.md)定义的漏斗运作，并向 [CMO](../../company/roles.md)/CEO 汇报。

## 接口

销售从[营销](../marketing/README.md)接收合格需求，售卖[产品](../product/README.md)交付的价值，按[战略](../strategy/business-model.md)定价，与[法务](../legal/README.md)签订合同，并把成交客户交接给[客户成功](../customer-success/README.md)。
