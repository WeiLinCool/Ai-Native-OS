# 运营

[English](README.md) | 中文

运营是让公司运转起来的连接组织：项目与项目群管理、内部流程、供应商与工具管理、知识与资产管理，以及让所有人保持对齐的节奏。它消除摩擦，让其他每个部门都能专注于自己的专业。它向 [COO](../../company/roles.md) 汇报。

## 接口

运营执行[管理节奏](../../guides/company-building-guide.md)中的跨部门节奏，与[产品](../product/README.md)和[工程](../engineering/README.md)协调交付，与[财务](../finance/README.md)和[法务](../legal/README.md)一起管理供应商，并让[文档](../documentation/README.md)与知识库保持可用。
