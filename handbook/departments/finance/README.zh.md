# 财务

[English](README.md) | 中文

财务让公司保持偿付能力、信息透明、具备融资能力。它掌管预测、预算、会计、收入与计费、成本管理，以及融资背后的财务模型。现金耗尽是企业最常见的死法；财务的职责就是确保这永远不会以措手不及的方式发生。它向 [CFO](../../company/roles.md) 汇报。

## 接口

财务把[战略](../strategy/unit-economics.md)的模型转化为预算与预测，跟踪 [DevOps](../devops/README.md) 与 [AI](../ai-engineering/README.md) 的成本，与[战略](../strategy/business-model.md)一起定价，并为[投资人关系](../investor-relations/README.md)提供数字。决策会沉淀到[决策记忆](../../../ai/memory/decision-memory.md)。
