# 战略

[English](README.md) | 中文

战略围绕产品构建公司。它负责创业生命周期、市场与竞争分析、商业模式、定价、单位经济、融资以及上市策略。它把来自 [研究](../research/README.md) 的已验证机会转化为可持续的生意，并向 [CEO](../../company/roles.md)、[CFO](../../company/roles.md) 和 [CMO](../../company/roles.md) 汇报。
