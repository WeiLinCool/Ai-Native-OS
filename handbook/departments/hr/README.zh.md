# 人力与 HR

[English](README.md) | 中文

人力与 HR 构建并维系那个构建其他一切的团队。它掌管招聘、入职、绩效与成长、薪酬以及文化 —— 既面向人类员工，也覆盖 [AI 智能体](../../../ai/agents/README.md) 与人类协作的方式。招聘是创始人杠杆最高的活动；这个部门让它变得可重复。它向 [COO](../../company/roles.md) 汇报。

## 接口

人力与 HR 按[组织结构](../../company/structure.md)为每个部门配备人员，与[财务](../finance/README.md)一起规划编制，并定义让新员工和智能体快速进入状态的入职路径。文化与角色期望可追溯到[公司原则](../../company/principles.md)。
