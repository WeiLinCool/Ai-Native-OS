# 投资人关系

[English](README.md) | 中文

投资人关系让投资人与董事会持续获得准确信息并保持参与，管理汇报与治理，并支持融资。与投资人之间的信任建立在持续、诚实的沟通之上 —— 好消息与坏消息都一样。它向 [CEO](../../company/roles.md) 和 [CFO](../../company/roles.md) 汇报。

## 接口

投资人关系从[财务](../finance/README.md)获取数字，从[战略](../strategy/README.md)获取叙事，并从[融资智能体](../../../ai/agents/strategy/fundraising-agent.md)获得融资支持；它产出董事会与投资人更新，并管理治理与股权结构表。
