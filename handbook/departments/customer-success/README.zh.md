# 客户成功

[English](README.md) | 中文

客户成功让客户在购买之后真正取得成功 —— 推动采用、健康度、留存与增购。留存会复利；维系并发展现有客户，比获取新客户更便宜、也更持久。它掌管客户关系与业务成果，与[上线后支持](../post-launch/support.md)（负责产品可靠性与工单）形成互补。它向 [COO](../../company/roles.md) 汇报。

## 接口

客户成功从[销售](../sales/README.md)接收交接，推动由[产品](../product/README.md)构建的能力被采用，把问题路由到[上线后支持](../post-launch/support.md)，将反馈输送给[产品](../post-launch/customer-feedback.md)，并与[财务](../finance/README.md)一起推进续约。
