# 研究

[English](README.md) | 中文

研究发掘他人忽视的机会，并把它们变成有防御力的产品。它用证据而非观点回答公司最重要的问题 —— *下一步该构建什么？*。它向 [Chief Scientist](../../company/roles.md) 汇报，并为 [战略](../strategy/README.md) 与 [产品](../product/README.md) 提供输入。

## 接口

研究把经过验证的问题与机会评分提供给 [战略](../strategy/startup-lifecycle.md) 和 [产品发现](../product/discovery.md)；技术发现交给 [工程](../engineering/README.md) 与 [AI 工程](../ai-engineering/README.md)；所有发现都留存于[研究记忆](../../../ai/memory/research-memory.md)和[知识库](../../../ai/memory/knowledge-base.md)。
