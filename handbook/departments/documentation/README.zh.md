# 文档

[English](README.md) | 中文

文档让公司的知识 —— 无论面向客户还是面向团队 —— 保持准确、易于查找且时时最新。它掌管产品文档、API 参考、内部知识，以及把它们串联起来的信息架构。它与[文档维护智能体](../../../ai/agents/post-launch/documentation-maintenance-agent.md)（负责对抗文档漂移）合作，并向 [COO](../../company/roles.md) 汇报。

## 接口

文档把[工程](../engineering/documentation-requirements.md)与[产品](../product/README.md)的工作转化为面向用户的文档，维护[运营](../operations/README.md)所依赖的内部知识，并让[文档记忆](../../../ai/memory/documentation-memory.md)索引保持准确、责任到人。
