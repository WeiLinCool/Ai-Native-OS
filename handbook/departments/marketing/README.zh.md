# 营销

[English](README.md) | 中文

营销让正确的客户知道产品，并被产品吸引。它掌管定位与信息传递、内容与 SEO、品牌与传播、增长，以及产品发布。再出色的产品，如果无人知晓也会失败；营销确保这不会发生。它向 [CMO](../../company/roles.md) 汇报。
