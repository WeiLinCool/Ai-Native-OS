# 数据

[English](README.md) | 中文

## 接口

数据向 [AI](../ai-engineering/README.md) 提供干净的数据集和特征，提供每个部门[仪表盘](../post-launch/dashboards.md)背后的指标，以及[产品](../product/analytics.md)用来决策的分析。它与[安全](../security/README.md)和[法务](../legal/README.md)在隐私与治理上协作。
