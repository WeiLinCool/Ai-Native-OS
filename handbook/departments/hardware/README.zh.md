# 硬件

[English](README.md) | 中文

硬件为产品包含原子而非只有比特的公司（机器人、无人机、嵌入式、IoT、设备）设计、构建并验证实体产品 —— 固件、电子与机械系统。只对包含硬件的公司启用；纯软件公司可让它保持休眠。它向 [CTO](../../company/roles.md) 汇报。

## 接口
