# 设计

[English](README.md) | 中文

设计让产品可用、无障碍、一致且值得信赖。它不是装饰 —— 它决定客户如何体验工程与产品构建的一切。设计负责用户行为研究、交互与视觉语言、设计系统以及无障碍标准。它向 [Chief Designer](../../company/roles.md) 汇报，并与 [产品](../product/README.md)
和 [工程](../engineering/README.md) 紧密协作。
