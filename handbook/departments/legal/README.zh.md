# 法务

[English](README.md) | 中文

法务保护公司免受法律与监管风险，并让公司能够安全地快速行动。它掌管合同、知识产权、许可、隐私政策与条款，以及监管合规。这里的错误代价高昂且难以逆转，因此法务是高风险动作的闸门。它向[首席法务官](../../company/roles.md)汇报。

## 接口

法务为[销售](../sales/README.md)和供应商评审合同，保护[工程](../engineering/README.md)与[研究](../research/README.md)创造的知识产权，设定由[安全](../security/README.md)执行的隐私条款，并就监管风险为[战略](../strategy/README.md)提供建议。高风险法律动作需要[人工审批](../../../ai/orchestration/approval-engine.md)。
