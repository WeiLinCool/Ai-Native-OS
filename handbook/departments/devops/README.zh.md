# DevOps

[English](README.md) | 中文

DevOps 构建让代码安全、可重复地进入生产的路径，并保持基础设施健康。它掌管 CI/CD、基础设施即代码、环境、发布工程与可靠性工具。它向 [CTO](../../company/roles.md) 汇报，并与[工程](../engineering/README.md)和[上线后](../post-launch/README.md)紧密协作。

DevOps 提供[工程](../engineering/workflows.md)交付所经的流水线、[上线后](../../../ai/agents/post-launch/infrastructure-health-agent.md)监控的基础设施，以及[安全](../security/README.md)所要求的安全加固。它自动化[发布管理](../post-launch/release-management.md)与[回滚](../post-launch/rollback.md)流程。
