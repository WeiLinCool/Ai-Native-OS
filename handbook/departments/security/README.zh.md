# 安全

[English](README.md) | 中文

安全保护公司、公司产品以及客户数据免受威胁。它掌管威胁建模、安全架构、渗透测试、漏洞管理、隐私与合规。它向[首席安全官](../../company/roles.md)汇报，其评审员可以拦截发布，且此类拦截无法被自动覆盖。

## 接口

安全制定由[工程](../engineering/security-standards.md)和 [AI](../ai-engineering/ai-security.md)落实的标准，通过[安全评审员](../../../ai/orchestration/security-reviewer.md)为发布把关，与[上线后](../post-launch/incident-response.md)一起驱动事故响应，并与[法务](../legal/README.md)在合规与隐私上协作。
