# 产品

[English](README.md) | 中文

> 卓越的工程把产品正确地构建出来。卓越的产品管理确保构建**正确的**产品。

产品部门通过结构化的发现、定义、优先级排序、交付与迭代，把客户问题转化为成功的产品。它由
[产品智能体](agents.md)执行，并与 [工程](../engineering/README.md) 和
[设计](../design/README.md) 紧密对接。

## 产品成功原则

一个成功的产品：

- 解决重要的客户问题。
- 易于理解，使用愉快。
- 创造可衡量的商业价值。
- 随客户增长而扩展。
- 基于证据持续演进。
- 保持一致、无障碍的用户体验。
- 强化公司的长期战略地位。

产品部门负责确保每次发布都让公司更接近可持续的[产品市场契合](metrics.md)与长期客户成功。
