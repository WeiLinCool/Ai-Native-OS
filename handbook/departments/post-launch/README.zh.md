# 上线后与维护

[English](README.md) | 中文

发布是起点，而不是终点。该部门让产品在上线后保持健康、可靠并持续演进 —— 通过监控、维护、事故响应、支持，以及一条自律的路径，一路走到生命周期终点。它的[维护智能体](agents.md)会持续检查产品，**即使没有任何开发者正在处理它。**

## 扩展后的产品生命周期（上线后阶段）

```
Launch → Monitoring → Maintenance → Continuous Improvement → Scaling
→ Customer Success → Product Evolution → Retirement (End-of-Life)
```
