# 医疗科技起步套件

[English](README.md) | 中文

一家打造涉及患者护理、临床决策或健康数据的软件或设备的公司。

## 继承内容保持不变

- 完整的[公司身份](../../handbook/company/)、[治理](../../handbook/governance/)，以及 AI 员工队伍（[编排](../../ai/orchestration/)、[记忆](../../ai/memory/)、[智能体](../../ai/agents/)）。
- [engineering](../../handbook/departments/engineering/)、[product](../../handbook/departments/product/) 和 [post-launch](../../handbook/departments/post-launch/) 部门，以及其他所有核心部门。
- [SDLC](../../handbook/workflows/sdlc.md)、[standards](../../handbook/standards/)、[templates](../../handbook/templates/) 和 [strategy](../../handbook/departments/strategy/)。

## 它新增和强调什么

| 增量 | 位置 |
|---|---|
| 领域智能体与启用的部门 | [agents.md](agents.md) |
| 领域标准 | [standards.md](standards.md) |

| 如何把它搭起来 | [getting-started.md](getting-started.md) |

## 为什么需要这些增量

医疗科技在常规软件风险之上，还背负着患者安全与监管的利害关系。这个套件让监管分类、临床证据和 PHI 保护在你动手构建之前就成为一等公民。

## 更换这个套件

要构建另一种公司类型，复制 [starter-kits/ai-startup/](../ai-startup/) 或这个目录，并把
领域增量换成你自己的 —— 继承模型是完全一样的。
